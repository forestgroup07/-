# Forest Group · 骰宝 Demo v1.0.0

PC 全屏骰宝交互演示（静图台面 + 可点筹码 / 大小 / 倒计时）。

## 功能
- 积分余额 2000（1000 印尼盾 = 1 积分）
- 筹码滑动：`10 → 20 → 50 → 100 → 200 → 500 → 1000 → 2000 → 5000 → 10000`
- 选中筹码抬起 + 光柱；未选中平贴（含 50）
- 大 / 小 1:1，倒计时 22 秒锁注结算

## 打开
本地：打开 `index.html` 或静态服务根目录。  
线上演示：`https://forestgroup.ai/?v=v100`

## 版本
见 `VERSION`（当前 **1.0.0**）。
